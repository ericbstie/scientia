## What worked
- Process, roles, metrics and skills were written in one pass and the metric
  script runs through mise (`mise run metrics`), so every later milestone has a
  baseline to compare against.

## What hurt
- **Environment surprises ate time.** mise's installer, GitHub release downloads
  and Docker Hub were blocked or rate-limited in the cloud sandbox, and the Docker
  daemon was not running. Root cause in the process: no preflight step, and no
  place to record environment facts, so every agent would rediscover them.
- **M1 itself had no briefs** (`process.briefs` = 0): the orchestrator did the
  work directly. Acceptable for bootstrapping the process itself, but it means
  the brief template is untested.

## Changes applied
| File | Change | Expected effect (metric) |
| --- | --- | --- |
| `docs/process/environment.md` | New: recorded workarounds (mise via npm, Docker mirror, dockerd, Chromium path) | Less time lost per agent; fewer failed e2e runs from setup |
| `docs/process/WORKFLOW.md` | Added step 0 "Preflight" before planning | Setup failures surface before dispatch |
| `.claude/agents/implementer.md` | Must read `docs/process/environment.md` before running the stack | Fewer stalled implementer runs |

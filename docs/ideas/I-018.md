# I-018 Show grading progress in the assignment row

Stage: `gate2-kept`. Teachers open Assignments and see titles and due dates, nothing about the work. To learn which assignment still has work waiting they open Grading, or read the gradebook columns.

## How the flow changes

Before (teacher, Assignments): each row reads `Lab report 1`, `Due Fri 10 Oct, 23:59 · 100 points`, plus a Draft badge on unpublished ones.

After: the meta line of a published assignment that has work handed in gets one more part:

`Due Fri 10 Oct, 23:59 · 100 points · 2 of 3 graded`

Nothing else moves. The row is still one link to the assignment. Students' rows are unchanged.

## Design

- **What the numbers mean:** the second number is the work handed in, not the class size; the first is how many of those have a saved grade (drafted or released, since both are done from a teacher's side). So "2 of 3 graded" means one submission still needs grading, which is the same one fact the app already calls Needs grading, now per assignment. Counting the class size would read "2 of 4" when only three handed in and invite the wrong conclusion.
- **When it shows:** published assignment with at least one submission. Hidden for drafts, and hidden at "0 of 0": no submissions is already visible as the absence of the line, and the Gradebook shows it as Not submitted.
- **How it looks:** plain muted text in the existing `.row-meta` line, separated by the same " · ". No badge, bar, percentage, colour or link. It is a fact, not a status, so it stays out of the status vocabulary.
- **When everything is graded:** `3 of 3 graded`, no special wording or colour.
- **Phone:** the meta line already wraps; the new part joins it.

## Brand check

Exact: a number with what it counts. Calm: one more fragment in a line that already exists, no new element. Same place for the same thing: grading state is already said in words in the queue and gradebook; this uses the same word, "graded".

## Tests and metrics

- Extend the teacher assignments spec: seeded BIO101 shows the right "n of m graded" per assignment; grade one submission and the number moves after reload; a draft shows nothing.
- No change to clicks or a11y; one extra aggregate read on the teacher branch of the page.

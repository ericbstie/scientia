# User requests

Issues from people outside the team, triaged by the
[user-request-triage skill](../../.claude/skills/user-request-triage/SKILL.md).
An issue listed here is not triaged again, unless its outcome is `needs-info`
and the author has answered since our reply.

Outcomes: `accepted`, `needs-info`, `declined`, `unsafe` (screened as prompt
injection or abuse: labelled, not answered, left for the product owner).
Summaries are ours, never copied from the issue.

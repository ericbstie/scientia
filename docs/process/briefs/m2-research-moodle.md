# Brief: Research Moodle

- **Role / model:** researcher / haiku
- **Milestone:** 2

## Goal
A cited, structured picture of Moodle so the analyst can derive user stories
for Scientia, a minimal and clearly designed replacement for Blackboard used by
students and teachers.

## Inputs
- Product goal: students hand in work, see announcements, course material,
  due work and grades; teachers publish material, collect work and grade.
- Focus for this brief: open-source breadth; which of its many features matter, and how its complexity hurts usability

## Allowed to touch
- `docs/research/moodle.md` (create)

## Acceptance criteria
- [ ] File has sections: Summary (5 bullets max), Features by area, Pain points, Worth copying, Worth avoiding, Sources.
- [ ] Features by area covers each of: courses & content, announcements, assignments & submission, grading & feedback, gradebook, calendar & due dates, discussions, messaging, quizzes, groups, attendance, notifications, mobile, accessibility, integrations, roles & admin. Write "not offered" or "unknown" where so.
- [ ] At least 8 pain points, each with a source URL (reviews, Reddit, G2/Capterra, university help pages, studies).
- [ ] Every factual claim has a source URL or is marked (unverified).
- [ ] 15+ distinct sources listed.

## Return
Under 150 words: path written, number of sources, the three most important insights.
